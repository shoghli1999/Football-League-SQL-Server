# Football league database (SQL Server)

My project for the Database Design course of my bachelor's at Islamic Azad University, South Tehran Branch (2021). I designed and built a relational database for the Iranian football league: teams, players, leagues and seasons, matches, goals and fouls.

What's in here:

- `erd.pdf` / `erd.vsdx`: the ER diagram (Visio).
- `databaseProject.mdf` and `databaseProject_log.ldf` (also zipped): the SQL Server database. Attach it in SQL Server Management Studio.
- `database export.pdf` / `.xlsx`: the table contents after I collected and cleaned the data.
- `shirin shoghli 9625512123.pdf`: my handwritten answers to the course questions in relational algebra, e.g. the team with the most points per league and season, the top scorer, and the players and teams with the most fouls.

The queries are written in relational algebra, not SQL. The database files are binary, so GitHub can't show the schema directly; the ER diagram is the quickest way in.
